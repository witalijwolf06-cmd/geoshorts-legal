2. What GeoShorts Publishing is

GeoShorts Publishing is a private command-line tool that the owner of the GeoShorts channel runs on the owner's own Windows computer. It has no server, no website login and no user accounts for other people. The only TikTok account it is used with is the owner's own GeoShorts account.

3. Data received from TikTok

When the owner signs in through TikTok Login Kit, the tool asks only for user.info.basic and user.info.profile. With them it reads open_id, username, display_name of the signed-in account. It uses these only to check that the signed-in account is the expected GeoShorts account and to link that account to the GeoShorts channel in the tool's own settings.

The tool does not request or read videos, comments, direct messages, followers, contacts, location, device data or statistics, and it uploads or posts nothing.

4. Where the data is stored

  • The refresh token, the app's client key and secret, the account's open ID and username, the granted permissions and two dates are stored in the Windows Credential Manager of the owner's computer.
  • The short-lived access token is kept only in memory while a command runs and is never written to a file.
  • The channel settings file of the tool contains the account's username and open ID.
  • Tokens and secrets are never written to log files or to version control.

5. Sharing

The data is not sold, shared or transferred to anyone. It leaves the owner's computer only in requests to TikTok's own API. GeoShorts Publishing uses no analytics, no advertising and no tracking.

6. How long it is kept, and how to remove it

  • The stored sign-in described in section 4 is kept until the owner removes it. It is not deleted automatically.
  • Signing out with the tool deletes the stored sign-in from the Windows Credential Manager. This does not withdraw the app's access on TikTok; that is done in the TikTok app under Settings, Security, Manage app permissions.
  • The refresh token stops working when its validity period set by TikTok ends, or earlier if access is withdrawn on TikTok. When the account was connected on 18 November 2026, TikTok reported a validity of 365 days; each use renews it. An expired token remains stored, but can no longer be used, until the owner signs out.
  • The username and open ID are also written to the tool's channel settings file. That file is kept in the tool's local version history and in backup copies on the owner's computer. No function of the tool removes them: they stay until the owner deletes them by hand. Deleting them from the settings file does not remove them from the version history or from earlier backup copies, which are kept without a fixed deletion date.
